# Community Guidelines & Discussion

Welcome to the **QualTest** community! We aim to foster an open, collaborative environment for wireless modem validation engineers and test automation developers.

---

## How to Get Help & Ask Questions
- **GitHub Discussions**: Use GitHub Discussions for general questions, architectural ideas, or usage assistance.
- **Documentation**: Check [docs/architecture.md](architecture.md) and [docs/protocol-stack.md](protocol-stack.md).

## Reporting Bugs
1. Search existing issues to ensure the bug has not already been reported.
2. Use the **Bug Report Template** (`.github/ISSUE_TEMPLATE/bug_report.md`).
3. Include clear steps to reproduce, environment information, and relevant log outputs.

## Requesting Features
1. Check the roadmap in `README.md`.
2. Open a feature request using the **Feature Request Template** (`.github/ISSUE_TEMPLATE/feature_request.md`).
3. Describe the proposed use case and target modem signaling scenario.
